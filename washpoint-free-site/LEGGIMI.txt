WASHPOINT — SITO STATICO GRATUITO

Questa cartella contiene il sito completo (index.html + assets). Non importare index.html da WordPress: va pubblicato come sito statico.

PUBBLICAZIONE GRATUITA CON GITHUB PAGES
1. Crea o accedi a un account gratuito su https://github.com
2. Crea un nuovo repository pubblico, ad esempio "washpoint-sito".
3. Carica TUTTI i file di questa cartella nella radice del repository: index.html e la cartella assets (non caricare la cartella contenitore che li racchiude).
4. Nel repository apri Settings → Pages.
5. In "Build and deployment" seleziona "Deploy from a branch", branch "main", cartella "/ (root)", poi Save.
6. Attendi la pubblicazione: GitHub mostrerà l'indirizzo gratuito nella sezione Pages, di solito https://NOMEUTENTE.github.io/washpoint-sito/.

COSTI
GitHub Pages è utilizzabile gratuitamente per un sito pubblico statico. Non acquistare un dominio: il sito avrà l'indirizzo gratuito github.io. Il sito WordPress esistente rimane separato e non viene cancellato.
